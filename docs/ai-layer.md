# AI 辅助层

## 架构

```
币安现货 / 永续 ─┐
CoinGecko       ─┼─> market_data.py ──> ai_regime.py ──> ai_regime.json
恐惧贪婪 / FRED ─┘                                      │
                                                        │ 开仓前读取
                                              Freqtrade ┘
                                                        │
                                                        v
                                              ai_report.py ──> Telegram
                                                        ^
                                              shadow_tracker.py
```

## 三个角色

### 1. 风控状态（ai_regime.py）

- 每天 08:10（北京时间，日线收盘后）运行
- 输入：8 个交易对日线、BTC 永续资金费率/持仓量/多空比、
  市场广度、CoinGecko 全市场、恐惧贪婪、FRED 宏观
- 输出：`risk_on / neutral / risk_off`，写入 `ai_regime.json`
- Freqtrade 在 `confirm_trade_entry` 中读取：
  - `risk_off` → 否决新开仓
  - 文件超过 26 小时未更新 → 放行（fail-open）

设计理由：

- **每天一次**，成本低、状态稳定、可审计
- **只做开关**，不决定买卖什么
- 失败时降级为放行，不阻塞交易

### 2. 晨报（ai_report.py）

- 每天 08:15 运行
- 输入：持仓、交易记录、8 个币行情、市场广度、衍生品、宏观、风控状态
- 输出：中文晨报，推送到 Telegram

### 3. 策略诊断（ai_strategy_review.py）

- 研究阶段使用，不参与实盘
- 输入：最新回测结果 + 策略源码
- 输出：问题诊断、过拟合评估、改进建议
- 注意：AI 的建议必须用样本外数据验证，不能直接采信

### 4. 影子跟踪（shadow_tracker.py）

- 每天 08:12 运行
- 不产生真实订单
- 跟踪 B1 动量轮动持仓与 RSI2 均值回归信号
- 写入 `shadow_state.json` / `shadow_history.jsonl`
- 每天推送一条摘要，30 天后自动发一次复盘

## 数据源

| 来源 | 内容 | 费用 |
|---|---|---|
| 币安现货 | 24h 行情、K 线、市场广度 | 免费 |
| 币安永续 | 资金费率、持仓量、多空比、主动买卖比 | 免费 |
| CoinGecko | 总市值、BTC/ETH/稳定币占比 | 免费 |
| Alternative.me | 恐惧贪婪指数 | 免费 |
| FRED | 美债收益率、美元指数、纳斯达克 | 免费（需 Key） |
| DeepSeek | 文本分析与 JSON 状态 | 按 token 计费 |

## 设计原则

1. **AI 只做过滤器和解释器，不做最终决策**
2. 所有 AI 输出都有确定性降级路径（失败 → 放行）
3. 状态一天内固定，避免盘中反复翻转
4. 不把 LLM 放进逐笔交易循环
5. 密钥只存在服务器，权限 600

## 成本

- 每日风控 + 晨报：约 2~4 千 token
- 一个月几毛钱到几块钱
- 策略诊断按需运行，单次约几毛钱

## 已知限制

- LLM 可能编造内容，必须把真实数据喂给它
- 不可复现，不能用于可回测的决策
- 数据源可能限流或变更
- FRED 数据为日频，通常滞后 1~3 个交易日
- 市场广度不含已退市标的，存在轻微生存者偏差
